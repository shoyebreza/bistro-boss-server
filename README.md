# Bistro Boss Server

A simple Node.js/Express server for the Bistro Boss project.

## Requirements

- Node.js
- npm

## Installation

1. Clone the project
2. Install dependencies:

```bash
npm install
```

## Setup

Create a `.env` file in the project root if you want to customize environment variables:

```env
PORT=3000
```

## Run the server

Start the application with:

```bash
node index.js
```

The server will run on:

- http://localhost:3000

## Project Structure

- `index.js` - Main server entry point
- `package.json` - Project dependencies and scripts
